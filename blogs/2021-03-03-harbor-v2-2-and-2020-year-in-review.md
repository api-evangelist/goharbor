We’re delighted to announce the general availability of Harbor v2.2. With notable features such as Multi-projects scoped robots Prometheus-driven telemetry Proxy caching capability extended to GCR, Quay.io, ECR, & ACR OIDC auth admin group support, achieving parity with LDAP auth Dell EMC ECS S3 storage support Aqua CSP Enterprise Scanner Integration Clair image scanner deprecated System level robot accounts With the introduction of system level robot accounts detailed in GH #8723, System Admins can create robot accounts that have permissions to multiple projects with specific API access beyond simple image pushes and pulls.
