Harbor v2.7.0 GA - exciting new features We’re delighted to announce the general availability of Harbor v2.7.0. New features Jobservice monitor Add the job service dashboard to monitor and control the job queues/schedules/workers Add jobservice monitoring api list pool, worker and stop running task by @stonezdj in 17658 feat: support customize session timeout by @chlins in 17767 Add REST API to list job queue status, pause/resume job queue and list schedulers by @stonezdj in 17707 Add Jobservice UI by @AllForNothing in 17722 The job service dashboard is a web-based interface that allows you to view and manage jobs that are running in the Harbor job service.
